# תבניות: README לכל תיקייה, ו-rules.md

הסקיל `cancel-cancer-setup` כותב מכאן את קובץ ה-`README.md` של כל תיקייה, ואת `rules.md`.

**איך משתמשים בתבנית:**

- מעתיקים את מה שבתוך בלוק הקוד, כמו שהוא.
- שם תפקיד בין גרשיים הפוכים (למשל `inbox`) מוחלף בשם התיקייה בפועל, לפי טבלת התיקיות ב-`kit.md`. כשהתיקיות באנגלית, אין מה להחליף.
- קובצי ההסבר בעברית, אלא אם המשתמש ביקש שפה אחרת. אז מתרגמים את התבנית בלי להוסיף ובלי להוריד.
- כותבים קובץ רק אם הוא לא קיים. `README.md` שכבר קיים לא נכתב מחדש, גם אם הוא שונה מהתבנית.

## inbox

```markdown
# `inbox` · קבצים חדשים

זו התיקייה היחידה שנוגעים בה. כל קובץ חדש נכנס לכאן.

- **מה נכנס:** סריקה או צילום של דף, PDF, קובץ מצורף ששמרתם ממייל, מסמך ששמרתם מאתר, הקלטה.
- **איך קוראים לקבצים:** לא צריך לשנות שם. אם כתבתם מספר על הדף, תנו לקובץ את אותו מספר, למשל `0007.pdf`.
- **מתי מתמלאת:** מפרק 4. משם כל קובץ עובר לתיקייה שלו. מה שצריך החלטה שלכם נשאר כאן, עם הערה.
```
