# Cancel Cancer · הערכה

ערכה חינמית של Benefits: סקילים ל-Claude שעוזרים לסדר את כל מה שמסביב למחלה של מישהו שאתם אוהבים. מסמכים, מיילים, תורים, הקלטות, כסף ומשימות במשפחה. כל פרק בסדרה מוסיף סקיל אחד.

כלי לסידור, לא ייעוץ רפואי, פיננסי או משפטי. כל החלטה ← עם הצוות המטפל. בחירום: מד"א 101.

## מה יש בריפו

| נתיב | מה זה |
|---|---|
| `plugins/cancel-cancer/` | הפלאגין. הסקילים נמצאים ב-`skills/`, ומה השתנה ב-`CHANGELOG.md` |

| `shared/cancel-cancer-contract.md` | החוזה של הערכה. זה המקור, ועותק זהה שלו נמצא בכל סקיל |

## איך מתקינים (פעם אחת)

צריך Claude בתשלום, ואת האפליקציה של Claude במחשב.

1. ב-Settings ← Capabilities מדליקים את Code execution and file creation.
2. Customize ← Plugins ← Add ← Add marketplace. מדביקים את הכתובת של העמוד הזה ב-GitHub, ולוחצים Add.
3. ב-Discover בוחרים את Cancel Cancer, ולוחצים Add.
4. מדליקים את Sync automatically, כדי שעדכונים יגיעו לבד.

## אחרי ההתקנה

1. יוצרים תיקייה ריקה במחשב, ושומרים בה את `downloads/start-here.md`.
2. פותחים שיחה, מוסיפים את התיקייה מתחת לתיבת ההודעה, וכותבים: "תקים לי את מפת התיקיות לפי ההסבר בקובץ start-here."
3. מחברים את Notion: Customize ← Connectors, מחפשים Notion ולוחצים Connect to Claude (או בדף הפלאגין, בלשונית Connectors). אחר כך כותבים בשיחה: "תקים לי את נושן של הסדרה."
4. דפים חדשים: כותבים מספר בעט בפינה של כל דף, סורקים, נותנים לקובץ את אותו מספר ושמים אותו ב-`inbox`. אחר כך כותבים: "הגיעו מסמכים חדשים."
5. מייל: ב-Gmail יוצרים תווית עם השם של מי שאתם מלווים (בצד שמאל, ליד Labels, לוחצים Create new label), ומסמנים בה כל מייל שקשור אליו. מחברים את Gmail: Customize ← Connectors, מחפשים Gmail ולוחצים Connect to Claude (או בדף הפלאגין, בלשונית Connectors). בדף של Gmail, תחת Tool permissions, השליחה נשארת Needs approval. אחר כך כותבים: "תעבור על המיילים בתווית של אמא." הסקיל קורא רק את התווית, ורק קורא.
6. טיוטה: כותבים "תכין טיוטה לרופאה עם כל המסמכים מהשבועיים האחרונים, וסיכום קצר. תגיד לי אילו קבצים לצרף. אל תשלח." הטיוטה נשמרת ב-Gmail, ב-Drafts, ובשיחה מקבלים רשימה ממוספרת של הקבצים לצרף. אתם מצרפים, עוברים ושולחים. אם תרצו, בדף של Gmail, תחת Tool permissions, אפשר לשים את השליחה על Blocked.
7. מחקר: כותבים "תכין תוכנית מחקר על הנושא שמטריד אותי", ומקבלים פרומפט בלי שום פרט מזהה. פותחים שיחה חדשה מחוץ לפרויקט, מכבים בה את Notion ו-Gmail (+ ← Connectors), לוחצים + ובוחרים Research, ומדביקים. כשהדוח חוזר, מדביקים אותו בחזרה וכותבים "חזר דוח המחקר". הדוח נשמר ב-`research`, והשאלות לצוות נרשמות בנושן.
8. רופא: כותבים "תכין לי דף אחד לפגישה עם הרופא". הדף נשמר ב-`doctor`, ולידו PDF באותו שם, לפתוח בטלפון או להדפיס. יש גם עותק `.html`: לחיצה כפולה פותחת אותו בדפדפן, ו-Ctrl+P מדפיס. מגיעים עם הדף ועם הקלסר. אחרי הפגישה כותבים "הפגישה הייתה, הנה מה שאמרו", והשאלות שנענו נסגרות בנושן.
9. פודקאסט: כותבים "תכין לי חבילה לפודקאסט לקראת הפגישה הבאה". בתיקייה `podcast` נוצרת תיקייה לחבילה, ובה מקור אחד עד ארבעה, ובשיחה מקבלים הנחיה למנחים. במחשב, ב-notebook.google.com, לוחצים Create new notebook ומעלים את כל הקבצים מהתיקייה של החבילה. ב-Studio לוחצים על העיפרון ליד Audio Overview, בוחרים עברית, מדביקים את ההנחיה ולוחצים Generate. מקשיבים באפליקציה Gemini Notebook בטלפון. לא לוחצים על האגודל למעלה או למטה, ולא משתפים קישור לנוטבוק. המנחים הם AI, וטועים לפעמים: מוודאים מול המסמך ומול הרופא.
10. הקלטה: מקליטים רק אחרי שמבקשים רשות, ורק כשאתם בשיחה. כותבים "יש לי הקלטה של פגישה עם רופא, תכין לי פרומפט לניתוח שלה במחברת", ועונים על שתי שאלות קצרות. ב-Gemini Notebook פותחים נוטבוק חדש, מעלים את קובץ ההקלטה (Upload a source, ובאפליקציה Audio File), ובצ'אט מדביקים את הפרומפט. את התשובה מעתיקים ומדביקים בחזרה בשיחה. הטקסט המלא נשמר ב-`transcripts`, המשימות והשאלות נרשמות בנושן, וכל תרופה, מינון, מספר ותאריך מסומנים "לבדוק מול הנייר". אם קובץ ההקלטה שמור ב-`inbox`, הוא עובר ל-`recordings`.
11. כסף: שומרים ב-`money` את קובצי החיובים מהאתר של הבנק ושל חברות האשראי (אקסל עדיף, או PDF), וכותבים "דינו, תעשה לי סדר בחיובים". הסיכום נשמר ב-`money`, ולידו עותק באקסל עם עמודת הערות. בשיחה מקבלים מה צריך לבדוק, מה חוזר כל חודש, ורשימה לסמן מה מוכר לכם ומה לא. כל הערה מצביעה על השורה בקובץ. הסקיל לא אומר מה לבטל: את ההחלטות מקבלים אתם, ואם צריך, עם בעל רישיון.
12. אתרים: באתר ציבורי (כל זכות, העמודים הפתוחים של ביטוח לאומי) כותבים "דינו, תכין לי פרומפט לתוסף, שיאסוף מהאתר כל זכות את הזכויות של חולה אונקולוגי, ויחזיר טבלה עם קישור לכל זכות". בכרום במחשב פותחים את האתר, לוחצים על הסמל של Claude (התוסף Claude in Chrome), מדביקים את הפרומפט, ואת התשובה מדביקים בחזרה בשיחה, או שומרים ב-`inbox`, וכותבים "חזרה התוצאה מהתוסף". באזור אישי (ביטוח לאומי, קופה, בנק) התוסף לא נכנס: אתם נכנסים, מורידים את המסמך ל-`inbox`, וכותבים "מה כתוב במסמך מהאזור האישי?". גישה לתיק בקופה, בלי הסיסמה של מי שאתם מלווים: "איך אני מקבל גישה לתיק של אמא בקופה?".
13. תזונה: שמים ב-`inbox` את ההנחיות הכתובות של התזונאית, מצרפים צילום או קישור של התפריט שיש לכם (למשל בר שייקים ליד המחלקה), וכותבים "דינו, אלה ההנחיות מהתזונאית, וזה התפריט שיש לנו. תבנה לי תפריט לשבוע, ותגיד מי קונה ומי מכין." עונים על כמה שאלות קצרות. התפריט נשמר ב-`menu`, ולידו דף להדפסה, לתלות על המקרר. ליד כל אפשרות כתוב למה היא מתאימה להנחיות. מה שלא כתוב בהנחיות לא נכנס, והוא שאלה לתזונאית. רשימת הקניות מגיעה בבלוק, להעתקה לוואטסאפ. כשמגיעות הנחיות חדשות, כותבים "הגיעו הנחיות חדשות מהתזונאית".

## דינו

דינו הוא הסוכן שמחזיק את הכל יחד. הוא פרויקט ב-Claude עם הוראות קבועות, והוא עובד עם התיקייה, עם נושן ועם הסקילים של הערכה.

1. ב-Claude פותחים Projects ← + New Project, וקוראים לפרויקט "🦖 𝐃𝐢𝐧𝐨".
2. לוחצים Set project instructions, ומדביקים את כל התוכן של `downloads/dino-instructions.md`.
3. משלימים את חמשת המקומות שבסוגריים מרובעים: השם של מי שמלווים, השם שלכם, מי עושה מה במשפחה, הקישורים לנושן, והשפה. במקום הקישורים מדביקים את הבלוק מהדוח של "תקים לי את נושן של הסדרה". לוחצים Save instructions.
4. באפליקציה של Claude במחשב מוסיפים לפרויקט את התיקייה של הערכה (זו שיש בה `kit.md`), ומאשרים ל-Claude לערוך בה.
5. פותחים שיחה בפרויקט וכותבים: "דינו, מה יש לנו בתיקייה, ומה עדיין חסר?"

- **שיחה חדשה לכל נושא,** בתוך הפרויקט. מה שדינו צריך נמצא בתיקייה ובנושן, ולא בשיחה. צריך משהו משיחה קודמת? מבקשים מדינו לחפש.
- **בטלפון:** אותו פרויקט. כדאי לשים אותו במועדפים. כשאין לדינו גישה לתיקייה, הוא עובד מנושן, ומה שצריך קבצים נרשם ב"ממתין למחשב" ומתבצע במחשב.

## עדכונים

גרסה חדשה מגיעה לבד כש-Sync automatically דלוק. אפשר גם ללחוץ Check for updates בדף הפלאגין.

ההוראות של דינו לא מתעדכנות עם הפלאגין, כי הן מודבקות ביד. כשנוסף סקיל, לא צריך להדביק אותן מחדש. אם ההוראות עצמן ישתנו, זה ייכתב ב-`CHANGELOG.md`.

## למי שמתחזק את הערכה

- **כל העלאה מעלה את `version`** ב-`plugins/cancel-cancer/.claude-plugin/plugin.json`. בלי זה, המשתמשים לא מקבלים את השינוי.
- **באותה העלאה,** בכל סקיל של הערכה: `kit-version` ב-`metadata` ובשורת הגרסה עולה לאותו מספר. `skill-version` עולה רק כשהסקיל עצמו השתנה.
- **לא משנים אף פעם `name`** של הפלאגין או של סקיל.
- **החוזה נערך רק ב-`shared/`,** ומועתק כמו שהוא ל-`references/cancel-cancer-contract.md` של כל סקיל.
- **שורה ב-`CHANGELOG.md`** לכל גרסה.
- **ההוראות של דינו** לא מונות סקילים. הסוגריים המרובעים היחידים בהן הם חמשת המקומות שהמשתמש ממלא. כל שינוי בהן נכתב ב-`CHANGELOG.md`, כי המשתמשים מדביקים אותן מחדש ביד.
